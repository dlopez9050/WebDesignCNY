# Web Design CNY

The website for Web Design CNY, served at https://webdesigncny.com by GitHub Pages.

- `index.html` is the whole site (styles and a little JavaScript are inline, no build step).
- `CNAME` tells GitHub Pages which domain to serve.
- `favicon.svg`, `apple-touch-icon.png` and `og-image.png` are the icons and the link-preview image.
- `robots.txt` and `sitemap.xml` help search engines; `404.html` is the not-found page.

This repo is public, so it holds only this site. No client work, prospect lists or mock-ups go here.
