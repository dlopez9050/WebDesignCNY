# Web Design CNY

The website for Web Design CNY, served at https://webdesigncny.com by GitHub Pages.

- `index.html`, `services.html`, `about.html`, `contact.html` are the pages.
- `assets/style.css` is the shared look, `assets/site.js` the shared behavior (menu, language switcher, scroll effects, phone demo, price builder, request form).
- `assets/i18n.js` holds the translations. English lives in the HTML; other languages are keyed by `data-i18n` ids.
- The pages, illustrations and translations are generated by `_build/build.py` (art in `_build/art.py`). Edit there and run `python3 _build/build.py`. The underscore folder is not published.
- `CNAME` tells GitHub Pages which domain to serve. `favicon.svg`, `apple-touch-icon.png`, `og-image.png`, `robots.txt`, `sitemap.xml` and `404.html` are supporting files.

This repo is public, so it holds only this site. No client work, prospect lists or mock-ups go here.
